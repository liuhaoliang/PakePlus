## 2. 阻断项修复明细（验证 → 实现 → 复验）

### 🔴 B2 —— 猪支撑面判定取错（engine.ts）

- **核实**：`blockTopUnder(x)` 在水平重叠块中取 `top` 最小者（屏幕最上方块），未过滤「位于猪脚上方的面」。第 1 关推演：猪脚 y=538，平台顶 542、顶梁顶 471、加高块顶 435 → 返回 435 → `|538-435|=103 ≥ 18` → 误判无支撑 → 首次结算后全部架空猪坠落。与评审结论一致，确认修复。
- **实现**（`app/src/game/engine.ts`）：
  - `blockTopUnder(x, feetY)` 增加 `feetY` 参数，只统计 `top ≥ feetY - SUPPORT_TOL`（新常量 `SUPPORT_TOL = 18`，与 `pigSupported` 容差一致）的承重面，并取其中最高的一面 —— 顶梁/高块的顶面位于猪脚上方，不再被当作支撑；
  - `pigSupported` 与坍塌落地检测（step 内）均改传 `p.y + p.r`。
- **配套初始落位修正**（`app/src/lib/mock/data.ts`）：`glassTower()` 两只猪原先半嵌在玻璃块内（中心=玻璃顶/顶+19px），修复后脚分别精确落在左玻璃顶（509）与右玻璃顶（478）——「玻璃块托猪、打碎玻璃 → 失去支撑」的设计意图随之成立。
- **复验**（转译真实 `engine.ts`+`data.ts` 执行）：
  - 开局 60 关全部猪被正确支撑（失败关卡 = []）；
  - L1（评审原始场景）：头顶有顶梁/加高块 → 有支撑（修复前为 false）；打掉顶梁/加高块仍有支撑；打掉平台（真承重面）→ 坠落 → 落到地面（猪脚 y=560.0）；
  - L4：左猪脚 509=左玻璃顶、右猪脚 478=右玻璃顶；打碎左玻璃 → 左猪坠落并落到下方木平台顶 542 且存活（落差 33px，落地速度 √(2×900×33)≈244 < FALL_DAMAGE_SPEED 320，无摔伤），右猪不受影响；
  - L5：石堡猪开局有支撑（地面），打掉堡顶横梁不坠落。

### 🟡 I1 —— bridge 桥下猪初始悬空（data.ts）

- **核实**：`y = g - 22 - pigR` → 猪脚 y=538，距地面 560 悬空 22px，脚下无块。确认修复。
- **实现**：改为 `y = g - pigR`（站在桥下地面上），注释同步为「猪站在桥下地面上」。
- **复验**：L3 桥下猪开局猪脚 y=560.0 = 地面，`pigSupported` = true。

### 🔴 B1 —— 星级阈值全局失配（data.ts）

- **核实**：原 `targetScore = 4000 + id*160 + difficulty*1000`（2/3 星再 ×1.6/×2.4），而单关理论上界 = 全部块分 + 全部猪分 + (鸟数-1)×1000。独立复算确认评审数据：第 1 关上界 4500 < targetScore 5160；1★ 不可达 58/60、2★/3★ 不可达 60/60。确认修复。
- **实现**（`app/src/lib/mock/data.ts` 新增 `scoreTargets(layout, birdCount)`，阈值由关卡实际内容推导，不再使用全局公式）：
  - 理论最高分 `maxScore = 块分Σ + 猪分Σ + (鸟数-1)×BIRD_BONUS`（至少要用 1 只鸟）；
  - **1★（targetScore）= min(round100(猪分Σ×0.95), 猪分Σ)** —— 击倒全部猪即达标，通关必得 ≥1 星（贴合弹弓类玩法惯例；`Math.min` 兜底保证阈值恒 ≤ 猪分Σ）；
  - **2★ = round100(猪分Σ + 块分Σ×0.5 + 奖励上限×0.35)**；
  - **3★ = round100(猪分Σ + 块分Σ×0.8 + 奖励上限×0.65)** —— 严格低于理论满分（裕量 ≥ 0.2×块分 + 0.35×奖励 ≥ 840px 分值 > 取整步长 100），保证存在可行解；
  - 阈值随章节内容（石块/猪王/加猪/4 鸟）自动缩放；确定性伪随机 `mulberry32` 调用顺序未变，布局与 SSG/SSR 同源性质不受影响。
- **复验**（60 关逐关断言，见 §3 达标表）：1★/2★/3★ 不可达均 **0/60**；`computeStars(猪分Σ, …) ≥ 1` 60/60（通关必得星）；`computeStars(maxScore, …) = 3` 60/60（完美通关满星）；阈值严格递增 60/60。实操标定示例（L1，3 鸟）：1★=1000（清猪即可）、2★=2500（猪+2 块+剩 1 鸟=2600 ✓）、3★=3500（全清+剩 1 鸟=3500 ✓、1 鸟通关=4500 ✓）。
