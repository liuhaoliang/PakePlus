## 1. 形态结论

| 结论项 | 结论 | 依据 |
|---|---|---|
| 产品形态 | 支付宝「网页&移动应用」下的**第三方纯 H5 小游戏**，React + TypeScript + AntD Mobile + Next（SSR/SSG） | 角色指令 + skill 核心范式 |
| 游戏核心 | 前端 Canvas + 物理引擎（Box2D 家族：`planck.js`/`matter.js`），弹弓牵引瞄准 → 发射 → 碰撞摧毁 → 过关判定 | 「愤怒的小鸟」玩法定义 |
| 为何是 H5 而非小程序 | 任务要求「可收录 + 可分享 + 支付宝 WebView 内嵌」，无 `my.*`、无 `AlipayJSBridge` 容器 JSAPI、无离线包 | skill「何时用/何时不用」与 guardrail |
| 双身份 | 同一公网 URL 对爬虫与用户吐相同 SSR/SSG HTML（公开内容无登录可拼出），支付宝内 hydrate 后追加登录态/功能字段 | architecture.md「双身份与降级」、反 cloaking |
| 品牌与版权 ⚠️ | **「愤怒的小鸟」是 Rovio 的商标与角色形象**，直接复用名称/素材有侵权风险 → 默认改为「原创卡通弹弓小鸟」主题（如「弹弹鸟：鸟蛋保卫战」），玩法同类、形象原创、可上免费图库素材 | 知识产权常识，列为待确认项之首 |
| 变现 | 默认**免费 + 分享裂变**；支付（`alipay.trade.wap.pay`）本期**只预留接口不实接**（需企业 AppId/密钥，任务未提供） | container.md 支付边界 |

**落地边界**：`/play/:id` 为 B 类功能页（CSR + `noindex`），浏览器打开时降级为「请在支付宝中打开」并走 `alipays://` scheme + `render.alipay.com` landing 唤起；公开页在浏览器与支付宝内均正常展示，浏览器仅拿不到登录态而自然降级。

## 4. 用户画像与旅程

- **用户 A · 消遣型休闲玩家**：利用碎片时间即点即玩。旅程：落地页首次进入 → 直接开第 1 关（免登录）→ 三星/通关 → 退出时检测未存进度提示 → 次日回来从上次关卡继续。留存靠存档与越来越多解锁的关卡。
- **用户 B · 竞技/炫耀型玩家**：追求高分与排名。旅程：从好友分享的「成绩卡片」落地进关卡 → 反复挑战刷高分 → 上传分数进排行榜 → 再分享我的成绩卡片拉好友比试。转化靠分享裂变与榜单刺激。
- **用户 C · 家长/陪伴型用户**：需要可控、无氪金、简单直接。旅程：从攻略页了解玩法 → 陪孩子玩低难度关卡 → 确认无内购/无强制登录 → 收藏/转发引导页。安全与零门槛是其留存关键。

## 6. 本期范围与内容规划

**本期 7 个页面（≥5 个）**，A 类 5 个、B 类 2 个；每页 ≥3 个有实质内容的区块：

- **`/` 首页（A）**：① Hero（游戏名 + 原创小鸟主视觉 + 「开始游戏」CTA）② 三步玩法（瞄准 → 发射 → 摧毁）③ 关卡精选 6 张缩略图 ④ 排行榜 Top 10 ⑤ 分享/打开引导。
- **`/levels` 关卡列表（A）**：① 章节 Tabs（3 章）② 关卡网格 60 关（编号/星级/锁定态）③ 进度概览条（已通关 X/60）。
- **`/level/:id` 关卡落地页（A，分享落地）**：① 关卡信息（名称/难度/最高分）② 关卡排行榜 Top ③ 「开始挑战」按钮（跳 `/play/:id`）④ 返回关卡列表。
- **`/leaderboard` 排行榜（A）**：① 总分榜 Tab（总分/单关最高）② 榜单列表 20+ 条（昵称/分数/进度）③ 我的排名卡（未登录降级为「登录后上榜」）。
- **`/guide` 玩法攻略（A）**：① 玩法总述 ② 技巧文章 3–5 篇（打三连星/角度技巧/道具使用）③ 常见问题 FAQ。
- **`/play/:id` 游戏关卡页（B，CSR + noindex）**：① 游戏 Canvas（弹弓 + 小鸟 + 猪堡 + 物理）② 顶部 HUD（分数/剩余小鸟/暂停）③ 结算弹层（星级/分数/分享/下一关/复活占位）④ 浏览器打开 → 「请在支付宝中打开」降级屏。
- **`/me` 我的战绩（B，登录态）**：① 进度概览（通关数/总星/最高分）② 关卡星级明细 ③ 历史记录列表 ④ 昵称/头像（未登录显示游客态）。

**mock 数据贴近真实业务（非「测试1/测试2」）**：
- 关卡 3 章 × 20 关 = **60 关**：字段含 `id`、`chapter`、`name`（如「第 1 章·小鸟出巢 第 1 关」）、`difficulty(1-3)`、`levelLayout`（弹弓坐标 + 猪群/木块/石块配置）、`targetScore`/三星阈值、`availableBirds`。
- 排行榜 **20+ 条**：昵称（弹弹侠007、酥酥不吃猪、蛋壳保卫队…）、总分、通关数、头像色块（无真实头像）。
- 攻略 **3–5 篇**：标题 + 摘要 + 正文段落 + 关键图。

## 10. 非功能要求

- **性能预算**：LCP ≤ 2.5s（P75，移动 4G）、CLS < 0.1、INP < 200ms；游戏主 bundle ≤ 200KB（gzip，物理引擎按 `/play` 懒加载）、首屏 JS ≤ 170KB；中端机稳定 ≥ 30FPS，首关可进入 ≤ 3s。
- **无障碍(a11y)**：周边页面语义化 + 按钮热区 ≥ 44px + 颜色对比达标；游戏本体 Canvas 玩法提供文字替代说明（周边页面达标，游戏核心 a11y 受限需说明）。
- **多语言**：本期中文；文案按 i18n 结构抽离，预留中/英。
- **兼容**：支付宝 iOS WKWebView / Android WebView + 主流移动浏览器；桌面降级可玩；viewport + 安全区 rem 适配 + 高 DPI。
- **监控/灰度**：Sentry + RUM；CDN 权重灰度（5% → 50% → 100%）+ feature flag；**上线时间与灰度节奏＝待确认**。
