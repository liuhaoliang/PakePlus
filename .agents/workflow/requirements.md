## 1. 形态结论

- **产品形态**：弹弓 + 物理碰撞 + 拆建筑/击倒目标的休闲益智 **第三方纯 H5 小游戏**，关卡制、单局短（< 90s）、可无限重玩，支持三星评分。
- **技术形态**：React + TypeScript + AntD Mobile（页面壳层）+ **Canvas + 物理引擎 Matter.js（游戏核心）**；纯 H5，不做支付宝小程序。
- **部署形态**：公网域名 + HTTPS + CDN，SSR/SSG 出可抓 HTML；同一份 HTML 双身份（公网网页 / 支付宝 WebView 内嵌）。
- **能力边界（skill 硬约束）**：
  - 没有 `my.*`、`AlipayJSBridge` 容器 JSAPI、离线包、多 WebView、自定义分享、私有 RPC —— 一律不使用，也不留 opt-in 占位。
  - 分享 = OG meta + URL（外部）/ URL + `alipays` scheme 唤起（App 内）。
  - 登录 = 服务端 `publicAppAuthorize` 跳转拿 auth_code 换 uid（可选 `ap.getAuthCode` 半屏增强）。
  - 支付 = 服务端 `alipay.trade.wap.pay` 生成跳转 URL（本期不接入，见 §5/§8）。
  - 多步流程/跨屏 = 标准 `location`/`history` + 客户端状态，不做原生多页面栈。
- **IP 结论**：不沿用「愤怒的小鸟」名称与 Rovio 角色/美术，改用**原创 IP**。工作名暂定《弹弓小队》（Slingshot Squad），角色/场景全部原创或使用 CC0/免费图库占位。
- **业务定位**：本期交付「可玩的完整小游戏」——≥20 关可玩、可分享、可看榜单、可游客游玩，成功标准为「可玩 + 无阻断性 bug」。
- **场景**：支付宝内为主 + 外部浏览器可达；公开玩法双端可玩，登录态/榜单功能在浏览器端自然降级。
- **既有工程**：工作目录为无关的 Tauri 壳项目（PakePlus），需按 skill 模板重建 H5 工程。无后端、无设计稿、无素材。

## 4. 用户画像与旅程

### 画像 A：碎片时间休闲玩家（最大盘）
- 特征：通勤/排队/睡前，期望「即点即玩」，不愿登录。
- 旅程：首次进入 → 首页「开始/选关」→ 玩 1~3 关 → 看星级结算 →（可选）分享成绩 → 隔几天再回来（靠本地存档续玩）。

### 画像 B：竞技/社交型玩家
- 特征：在意分数与名次，愿意登录绑定身份。
- 旅程：首次进入 → 打完基础关卡 → 被排行榜/每日挑战吸引 → OAuth 登录 → 冲榜/秀成绩 → 分享拉好友比分数。

### 画像 C：支付宝生态内「杀时间/尝鲜」用户
- 特征：通过分享卡片/入口冷启动，可收藏可复访。
- 旅程：分享落地页 → 首屏即游戏入口 → 游客玩 → 体验好则继续/收藏 → 下次从最近关卡继续。

**关键设计原则**：公开玩法零门槛（无需登录即可玩）；登录只在「提交成绩到榜单 / 查看我的名次」处出现；浏览器端自然降级为游客 + 本机存档。

### 6.2 每页区块（每页 ≥3 个实质区块）

- **首页 `/`**：① Hero 区 + 「开始游戏/继续游戏」CTA；② 玩法介绍（三步图解：拖拽瞄准 → 发射 → 摧毁目标）；③ 关卡/星数总进度概览（20 关 × 3 星 = 60 星）；④ 排行榜 Top5 预览；⑤ 分享/打开支付宝入口。
- **关卡列表 `/levels`**：① 章节/主题筛选（丛林·沙漠·雪地·城镇，分 4 章 × 5 关）；② 20 个关卡卡片（编号、名称、星级 0~3、锁定态、最优得分）；③ 星级总进度条 + 计数；④ 每日挑战入口卡（日期、主题、剩余可挑战标记）。
- **游戏页 `/play/:id`**：① Canvas 游戏区（弹弓/目标/障碍/物理）；② 顶部菜单（重开、音量开关、返回选关）；③ 轨迹预览 + 剩余可用鸟/道具栏；④ 局内弱网/空态兜底。
- **结算页 `/result/:id`**：① 得分 + 0~3 星揭示；② 生成成绩分享卡按钮；③ 重玩 / 下一关；④ 排行榜位次（本机历史最优 + 若登录则提交成绩）。
- **排行榜 `/leaderboard`**：① 公开总榜 Top20（昵称/头像/总星/分数/名次）；② 「我的名次」（游客提示登录后可见）；③ 好友榜（预留）；④ 榜单规则说明（分数=摧毁目标+剩余鸟奖励+星数权重）。
- **分享落地 `/share/:shareId`**：① 成绩卡（分享者昵称、得分/星级/关卡名、封面图）；② 「立即挑战」主 CTA；③ 打开支付宝引导（浏览器唤起 scheme）；④ 相关关卡推荐。
- **攻略 `/guide/:slug`**：① 图文教程正文（弹弓力度/弹道/三星技巧，真实图文非「测试」）；② 适合关卡列表；③ 相关关卡入口。

### 6.3 数据量约定（mock 真实化）

- **关卡**：≥20 条。字段：`id`、`name`（如「第一关·丛林清晨」）、`chapter`（丛林/沙漠/雪地/城镇）、`theme`（背景主题）、`stars`（0~3）、`bestScore`、`locked`、`thumbnail`（缩略图 URL）、`birds`（可用鸟种类/数量）、`obstacles`（障碍物配置）。
- **排行榜**：≥20 条。字段：`rank`、`nickname`、`avatar`、`totalStars`、`score`。
- **攻略**：1 篇完整图文（标题/摘要/正文分节/配图），内容真实（弹弓玩法技巧、三星要点、难度曲线），避免「测试1/测试2」。
- **每日挑战**：1 条（日期 + 主题 + 关卡配置指针）。

## 8. 接口清单

> 本期全部为 **前端 mock + localStorage**，但按「未来真实后端形状」设计，字段贴近真实业务；鉴权方式预留。

| 方法/路径 | 用途 | mock 实现 | 鉴权 | 备注 |
|---|---|---|---|---|
| `GET /api/levels` | 关卡列表（20 条） | 静态 JSON/构建期生成 | 无 | 公开 |
| `GET /api/levels/:id` | 单关配置 | 静态 JSON | 无 | 公开；`id="daily"` 返回每日挑战 |
| `GET /api/leaderboard/top` | 公开总榜 Top20 | 静态 mock JSON | 无 | 公开 |
| `POST /api/score` | 提交成绩 | mock：写 localStorage | OAuth（预留 Bearer/uid） | 登录态；未登录降级为仅本机 |
| `GET /api/me/rank` | 我的名次 | mock：本机合并 | OAuth | 登录态；预留 |
| `POST /api/share` | 生成分享卡/短链 | mock：本地生成 shareId | 无/OAuth（可选） | 生成 title/desc/og |
| `GET /api/share/:shareId` | 分享卡数据 | mock：静态/由参数推导 | 无 | 公开 |
| `GET /api/guide/:slug` | 攻略内容 | mock：静态 Markdown/JSON | 无 | 公开 |
| `POST /api/pay/create` | 下单（wap.pay） | 预留，本期不实现 | 服务端私钥 + AppId | 本期不做，接口形状预留 |

**鉴权约定**：登录态接口预留 `Authorization` 头（服务端换得的 uid/凭证）；本期 mock 全部走 localStorage，POST 类接口仅在浏览器/支付宝内命中该用户身份时写回本机。

**能力接入点（container 层，G3 实现）**：
- 授权：`publicAppAuthorize` 服务端跳转 → 回跳换 uid；H5 内可选 `ap.getAuthCode` 半屏。
- 唤起：`alipays://platformapi/startapp?appId=20000067&url=...` → `https://render.alipay.com/p/s/i/?scheme=...` landing（非 alipay.com 域名需白名单）。
- 支付：本期不接；未来走 `alipay.trade.wap.pay` 服务端跳转。

## 10. 非功能要求

- **语言**：简体中文单语言；文案统一走中文常量，不做 i18n 框架（预留文案集中管理）。
- **无障碍（a11y）**：尽力不强制（对比度、可缩放、焦点可达、触摸目标 ≥44px；不设 A 级硬性验收）。
- **性能预算**：
  - LCP < 2.5s；CLS < 0.1；INP/交互 < 200ms。
  - 首屏 JS bundle < 300KB（gzip 后）；**游戏模块（物理引擎 + Canvas）按需懒加载**，不阻塞首屏。
  - 公开页 SSR/SSG 直出；图片走 CDN + 响应式 `srcset`/懒加载；避免模块顶层 `window` 触发 hydration 报错。
- **灰度与发布**：公网域名 + HTTPS；灰度用 **CDN 权重 + feature flag**（不使用离线包/客户端开关）；robots.txt 屏蔽 B 类，sitemap.xml 仅含 A 类。
- **兼容**：iOS WKWebView + Android WebView（支付宝内）+ 主流移动浏览器（Safari/Chrome）；桌面可玩（鼠标拖拽降级）；无 `window`/`document` 时服务端不报错。
- **合规**：不使用 Rovio IP 名称/美术/音效；素材来源可追溯（原创或 CC0/免费授权）。
